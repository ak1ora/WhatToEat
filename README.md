# WhatToEat 🍽️

Android-приложение для подбора рецептов по ответам на адаптивный опросник. Пользователь отвечает на вопросы о приёме пищи, времени, сложности, кухне и доступных продуктах — приложение подбирает подходящие блюда с рецептами.

## 🛠 Стек технологий

| Категория | Технология |
|-----------|------------|
| **Язык** | Kotlin 1.9+ |
| **UI** | Jetpack Compose (Material 3) |
| **Архитектура** | Clean Architecture (single-module) |
| **DI** | Hilt |
| **Навигация** | Navigation Compose |
| **Сеть** | Retrofit + OkHttp + Kotlinx Serialization |
| **БД** | Room (кэш, избранное, история) |
| **Асинхронность** | Coroutines + Flow |
| **Изображения** | Coil |
| **API рецептов** | TheMealDB (основной) + Spoonacular (опционально) |

## 📱 Функциональность

### Адаптивный опросник
1. **Приём пищи** — завтрак / обед / ужин / перекус
2. **Время на готовку** — ползунок 5-120 мин
3. **Сложность** — очень просто / просто / средне (показывается если время < 15 мин)
4. **Кухня** — любая / русская / итальянская / азиатская / мексиканская / средиземноморская / американская / вегетарианская / веганская / ЗОЖ
5. **Продукты под рукой** — мультивыбор из 18 популярных ингредиентов
6. **Исключения** — аллергены и нелюбимые продукты (глютен, молочка, орехи, морепродукты и др.)
7. **Дополнительно** — текстовое поле для калорийности, белков, способа приготовления

### Рецепты
- Поиск через TheMealDB API
- Эвристический скоринг совпадения (время, сложность, кухня, ингредиенты, диета)
- Карточки с фото, временем, сложностью, % совпадения
- Детальный экран: ингредиенты (чек-лист), пошаговая инструкция, теги, ссылки на YouTube/источник
- Добавление в избранное, история просмотров

### Офлайн
- Кэширование последних 50 рецептов в Room
- Избранное и история доступны без интернета
- Жёсткий экран ошибки с кнопкой «Повторить» при отсутствии сети

## 🚀 Запуск

1. Клонируйте репозиторий
2. Откройте в Android Studio (Koala 2024.1.1+)
3. Синхронизируйте Gradle
4. Запустите на эмуляторе или устройстве (API 24+)

## 🔑 API Ключи

Приложение работает с **TheMealDB** без ключей (бесплатно, без лимитов).

Опционально: добавьте **Spoonacular API Key** в настройках для расширенного поиска.
Получите ключ на [spoonacular.com/food-api](https://spoonacular.com/food-api).

## 📦 Сборка релиза

```bash
./gradlew assembleRelease
```

Подпишите AAB и загрузите в Google Play Console.

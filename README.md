# 🍽️ WhatToEat — что приготовить?

Приложение для Android, которое подбирает блюда по продуктам под рукой, времени на готовку и вашим предпочтениям. Подборка и списки ингредиентов доступны без интернета.

**[Скачать APK для Android](https://github.com/ak1ora/WhatToEat/releases/download/offline-v1.0/app-debug.apk)** · [Страница релиза](https://github.com/ak1ora/WhatToEat/releases/tag/offline-v1.0)

## Как установить

Подойдёт телефон или планшет с Android 6.0 или новее. Для скачивания войдите в аккаунт GitHub с доступом к приватному репозиторию.

1. Скачайте `app-debug.apk` на устройство и откройте его.
2. Если Android запросит разрешение, включите установку из этого источника для браузера или файлового менеджера, в котором открыли APK. [Справка Android](https://support.google.com/android/answer/9457058?hl=ru)
3. Нажмите **Установить**, затем откройте **WhatToEat**.

## Как подобрать блюдо

1. Выберите приём пищи и укажите, сколько времени есть на готовку.
2. Выберите сложность и кухню, отметьте продукты, которые есть дома, и то, что хотите исключить.
3. Пройдите опрос до конца. В подборке будет до пяти блюд со временем приготовления, списками ингредиентов и ссылками на полные рецепты. Для открытия этих ссылок нужен интернет.

Если подборка пустая, попробуйте увеличить время на готовку или выбрать кухню **Любая**. Светлую и тёмную тему можно переключить кнопкой вверху экрана.

# WhatToEat для Android

Это офлайн Android-оболочка для исходного веб-приложения в `index.html`.
Он остаётся единственным источником интерфейса, рецептов и логики.

## Сборка APK

1. Откройте эту папку в Android Studio.
2. Установите предложенные Android SDK Platform 35 и Android SDK Build-Tools.
3. Выберите **Build → Build APK(s)**.
4. Debug APK будет в `app/build/outputs/apk/debug/app-debug.apk`.

Android Studio предложит создать Gradle Wrapper при первой синхронизации; его можно сохранить в проекте для сборки через терминал.
